## 1. Decisions (made here, with reasons)

**D575-1. A new kind `hex-census` and a new store module. Do not widen `guid-census`.**
- `guid-census` is 530's measuring instrument. Census 2655 is 575's frozen Verify input, and census 2675 is 530's R3.
- Teaching its `RAW_SHAPES` the cf35 shape would relabel the `ted other` cell that 530's and 575's records cite.
  Adding a class switch to `Spec::GuidCensus` would change a Spec that is serialized in the jobs table.
- The new module reuses guid_census's and guid_twins's `pub(crate)` statements unchanged (§2.2). The only new SQL is
  the window statement.

**D575-2. Population: every organization whose stored identifier is 32 ASCII hex digits.**
- `normalise_identifier_with` turns every cf35 raw into 32 upper-case hex (triage, "How the value is keyed"). So the
  population is complete for rows whose identity came from a cf35 mention.
- The window statement reads `length(identifier) >= 16`, not `= 32`. The rowid range reads the same pages either way,
  and the wider filter also re-takes the `hex_hash` total. That is the U1 cross-check against issue 300's 273,982
  (run 1332).
- Not reached: a cf35 mention bound to a row whose stored identifier is not 32 hex (a merge survivor). Phase 2 counts
  those wherever they share a notice with a class mention (`cf35_off_class`). The rest is listed under
  `not_measured`.

**D575-3. Roles come per mention from `tender_version_parties` and `tender_version_bid_parties`, by mention key.**
- The issue's U1 text asks for exactly this: "Role comes from `tender_version_parties` at the mention's notice and
  section".
- Phase 2 reads every ORG mention of each notice that holds a cf35 mention. That one read gives:
  - the buyer bar at mention level;
  - the shape × role matrix of the Avenue-Web notices (buyers' account numbers next to cf35; AddInfo mixed);
  - the within-notice twins (option b's reach);
  - the blank-name count;
  - U5's tenderer-key count, all without a global mention array.
- Strata, in precedence order: `buyer` > `add_info` > `sprovider` > `mediator` > `review` > `tenderer` > `other` >
  `no_role` (§2.4).

**D575-4. One shape classifier, in store and `pub`, for U3 to reuse.**
- `store::hex_raw_shape` / `store::is_cf35`: trimmed, case-blind, `^[0-9A-F]{8}-[0-9A-F]{4}-[0-9A-F]{4}-[0-9A-F]{16}$`.
- ingest already depends on store (`store::Mention`, `store::GuidKeep`). So U3's refusal in `gated_identifier`
  (`project.rs:5475` at this HEAD) calls `store::is_cf35`, and the census and the gate agree by construction.

**D575-5. Targets and the A6 city screen mirror 530's planner exactly.**
- Key: `(org_name_norm(mention name), register_jurisdiction(mention country))`. This is the resolver's fallback key
  (`canonical.rs:23645-23652`).
- Target: the identifier-NULL row of that key, lowest id (`guid_twin_targets_sql`, which seeks
  `organizations_name_country`).
- Each target also gets its mention count and the BT-513 cities of its newest 50 mentions, plus each cf35 mention's
  own city. These are 530's A6 flags: (a) city absent from the target's set, (b) a multi-city target, (c) planned
  mentions with two or more cities.
- A key with no NULL row is `missing`: U4's dissolve would mint it, as the resolver does (`canonical.rs:23711-23727`).
- The CCIRA keys are listed whole (prefix `comite consultatif interregional` after `guid_twin_city_fold`), because U2
  must read every CCIRA homonym.

**D575-6. R2's random draw is built in.** U2 needs "a random 60 stratified by role (SProvider, review, mediator,
AddInfo)".
- The census takes 15 per stratum in salted order (`guid_twin_sample_key(id, 575_001)`).
- It also lists whole, up to 2,000 each, every row that a bar names: buyer-role, multi-Tender, stable, KEEP_530.
  So U2 reads straight off the report.

**D575-7. Reported here, not measured.**
- The corpus-wide `eu`-scheme mention total. 365's 252,658 is unscoped, and taking it means a full scan of
  `organization_mentions`. It is no U2 bar. `notice_mentions.by_shape_scheme` gives the scheme of every ORG mention
  inside the cf35 notices, which answers "is cf35 ⊂ eu".
- The A6 reverse walk beyond a target's newest 50 mentions (530's `GUID_TWIN_TARGET_NEWEST`).
- Both are listed in `not_measured`.

**D575-8. `stable_mentions` and `samples` as `guid-census` takes them.** `stable_mentions` defaults to 100 and 2 or
under is refused. `samples` defaults to 30, clamped to 1–200. `dry_run: false` is refused. The params are
`hex-census dry stable_mentions=100 samples=30`.

**D575-9. No CHANGELOG entry, and no /docs or OpenAPI change.**
- CHANGELOG covers only the public /v1 API, and a dry job changes no answer. Precedent: 530 U1's `guid-census` added
  no entry; the 530 entry came with the gate.
- U3 brings the /docs sentence and the CHANGELOG entry.

**D575-10. The run is a class-Z segment of the 551 kit.**
- The kit exempts only dry `refold-lot-sum` jobs (`wkit.py:156`).
- Close the segment without `--corrected`. `segment.py` accepts a typed 0 only for `repair-notice-instants`

### 2.4 Pure helpers (pub where U3 or the supervisor reads them)

```rust
/// A raw BT-501's shape (one of HEX_CENSUS_SHAPES): trimmed, case-blind.
/// cf35 = 35 chars, dashes at 8, 13, 18, hex elsewhere (ColdFusion CreateUUID, 8-4-4-16);
/// rfc36 = 36 chars, dashes at 8, 13, 18, 23; hex32 = 32 hex; tenderer_key = four dash-separated digit
/// groups (Avenue-Web's `<procedure>-1-<lot>-<n>`); digits = all digits; other; none = NULL/blank.
pub fn hex_raw_shape(raw: Option<&str>) -> &'static str {
    let v = raw.map(str::trim).unwrap_or_default();
    if v.is_empty() { return "none"; }
    let b = v.as_bytes();
    let hex_at = |dashes: &[usize]| b.iter().enumerate().all(|(i, c)| if dashes.contains(&i) { *c == b'-' } else { c.is_ascii_hexdigit() });
    if b.len() == 35 && hex_at(&[8, 13, 18]) { return "cf35"; }
    if b.len() == 36 && hex_at(&[8, 13, 18, 23]) { return "rfc36"; }
    if b.len() == 32 && b.iter().all(u8::is_ascii_hexdigit) { return "hex32"; }
    let groups: Vec<&str> = v.split('-').collect();
    if groups.len() == 4 && groups.iter().all(|g| !g.is_empty() && g.bytes().all(|c| c.is_ascii_digit())) { return "tenderer_key"; }
    if b.iter().all(u8::is_ascii_digit) { return "digits"; }
    "other"
}

/// Issue 575: the platform key's published shape (U3's gate calls this).
pub fn is_cf35(raw: &str) -> bool { hex_raw_shape(Some(raw)) == "cf35" }

/// A mention's stratum from its sorted, distinct roles (parties as stored, bid parties prefixed `bid-`),
/// in HEX_CENSUS_STRATA precedence. eForms roles are read after their scope (guid_twin_role_after_scope);
/// the legacy names (EFORMS_ROLE_MEANING, project.rs:11671) map alike.
pub fn hex_stratum(roles: &[String], role_class: fn(&str) -> &'static str) -> &'static str {
    let any = |f: &dyn Fn(&str) -> bool| roles.iter().any(|r| f(r));
    let after = |r: &str| guid_twin_role_after_scope(r).to_owned();
    if any(&|r| role_class(r) == GUID_ROLE_BUYER) { return "buyer"; }
    if any(&|r| after(r) == "AddInfo" || r == "further-information") { return "add_info"; }
    if any(&|r| after(r) == "SProvider" || r == "service-provider") { return "sprovider"; }
    if any(&|r| after(r) == "Mediator" || r == "mediation-body") { return "mediator"; }
    if any(&|r| matches!(after(r).as_str(), "ReviewOrg" | "ReviewInfo") || matches!(r, "review-body" | "appeal-information")
        || role_class(r) == GUID_ROLE_REVIEW_INFO) { return "review"; }
    if any(&|r| role_class(r) == GUID_ROLE_TENDERER || r.starts_with("bid-")) { return "tenderer"; }
    if roles.is_empty() { "no_role" } else { "other" }
}

fn hex32(v: &str) -> bool { v.len() == 32 && v.bytes().all(|b| b.is_ascii_hexdigit()) }
/// A scheme as reported: trimmed, lower-cased, "(none)" for NULL/blank.
fn scheme_key(s: Option<&str>) -> String { match s.map(str::trim) { Some(t) if !t.is_empty() => t.to_lowercase(), _ => "(none)".into() } }
```

`by_shape` key: the row's distinct `notices.source` values (sorted, joined by `+`; `(no notice)` for a mention with
no notice row), a space, then the distinct shapes of its mentions in HEX_CENSUS_SHAPES order joined by `+`.
`(no mention)` stands in for either half on an orphan. Examples: `ted cf35`, `doe+ted cf35+hex32`, `ted rfc36`.

### 2.6 `impl Db { pub async fn hex_census(&self, args: HexCensusArgs<'_>) -> turso::Result<HexCensusReport> }`

Doc comment: what it writes (nothing), the three phases below, the indexes, the stop points, and memory. Memory is
one record per class row, about 250 B with its strings, so about 60 MB at 230k rows. Targets and phase-2 chunks are
small.

**Phase 0.** For each of HEX_CENSUS_INDEXES, if `!self.has_index(i)` → `Err(turso::Error::Error(format!("hex-census
refused: {i} is absent (a rebuild?), so every chunk would scan its table; run `reindex` first. Nothing was read")))`.
Then `reader = self.reader()`, and `max_id` comes from GUID_CENSUS_MAX_ID_SQL. On every `stop()` below,
return `Ok(HexCensusReport { stopped: true, ..Default::default() })`.

**Phase 1: the walk** (mirror guid_census.rs:574-618 and its batch at :626-792).
- Windows `(lo, hi]` of `args.window.max(1)` up to `max_id`. Read `stop()` before each window.
- For each row of HEX_CENSUS_ORGS_SQL:
  - `id_rows_16plus += 1`;
  - `if (args.hex_hash)(&identifier) { hex_hash_rows += 1 }`;
  - `if hex32(&identifier)`, push it pending.
- Batches of `args.batch.clamp(1, HEX_CENSUS_BATCH)`. Read `stop()` before each batch and before each IN chunk of
  every read below.
  1. `guid_census_mentions_sql`: per row, count mentions, collect notice ids, and OR the shape bit of each
     `hex_raw_shape(raw)`. A cf35 mention also gets `cf35 += 1` and its notice goes into the row's cf35 notice list.
     `hex32_mentions += 1` per mention.
  2. Distinct notices of the batch: `notices_read += n`. Then `guid_census_notices_sql` (source, profile,
     published_at) and `guid_census_tenders_sql`.
  3. Per row:
     - tenders = the distinct Tenders of all its notices;
     - sources and profiles = the distinct values over its notices;
     - first_published = the min over its notices;
     - `by_shape[key].add(row)`, plus `v4_by_shape[key] += 1` when `(args.is_v4)(identifier)`.
       The row's `stable` here is `mentions >= args.stable_mentions` (known from the args), so `by_shape`'s
       `stable` is whole; finish recomputes it identically for the class rows.
  4. A row with cf35 > 0 is a **class row**. Push a `ClassRow` with: id, country, identifier, served name, mentions,
     cf35, notices, all tender ids sorted, first_year (`unix_year`), source key, profile key, shape bits,
     `v4 = is_v4`, `kept = args.keep.contains(identifier)`, and `first: None`, `stratum: "no_role"`, `twin: false`,
     `target: None`.
     - Insert its cf35 notices into a walk-wide `BTreeSet<i64>`, and their Tenders into `class_tenders`.
     - `first_notice_id` / `first_published` are mins over the cf35 notices.
  - Progress: `(lo, "walking organizations: id {lo} of {max_id}, {hex32} 32-hex row(s), {class} cf35 row(s)")`.

**Phase 2: the cf35 notices**, ascending, in IN chunks. Read `stop()` before each of the four reads of each chunk.
1. `guid_twin_notice_mentions_sql`.
2. `guid_twin_parties_sql` → `roles[(notice, section)]` (BTreeSet).
3. `guid_twin_bid_parties_sql` → the same, each role prefixed `bid-`.
4. `guid_twin_cities_sql` with GUID_TWIN_CITY_FIELD bound last. Keep the lowest ordinal per `(notice, section)`,
   folded by `guid_twin_city_fold`. Skip an empty fold.

The mentions come in PK order (notice_id, section_id), so process them per notice. For each mention:
- shape = `hex_raw_shape(raw)`; roles = the sorted Vec; role_keys = the roles, or `["(none)"]`.
- `mentions += 1`, `by_shape[shape] += 1`, `by_shape_role[shape][role] += 1` for each role key, and
  `by_shape_scheme[shape][scheme_key] += 1`.
- If shape is `tenderer_key`:
  - `tenderer_key.mentions += 1`;
  - insert org into a row set, and the first digit group (u64) into a procedure set;
  - insert raw into `stripped[raw without '-']` (a BTreeSet of raws). At finish, collisions = keys with 2 or more
    raws.
- If shape is `cf35`:
  - `cf35_mentions += 1`.
  - Org class: `class_at` has it → `cf35_on_class_rows`; else if org > max_id → `cf35_above_max_id`; else →
    `cf35_off_class`.
  - stratum = `hex_stratum(&roles, args.role_class)`; `cf35_by_stratum[stratum] += 1`;
    `cf35_role_sets[roles.join("+") or "(none)"] += 1`; `if stratum == "buyer" { cf35_buyer_mentions += 1 }`.
  - norm = `org_name_norm(name.unwrap_or(""))`; `if norm.is_empty() { cf35_blank_name_mentions += 1 }`.
  - Key country = `country.map(trim).filter(non-empty).map(|c| register_jurisdiction(c).to_owned())`. Unkeyed
    (norm empty or no country) → `cf35_unkeyed_mentions += 1`.
  - Else find or create the target: `cf35_mentions += 1`, insert org into its row set, set `published_name` if
    unset, and if the mention has a city, `planned_cities[city] += 1`, else count it without a city.
  - Twin bookkeeping (non-empty norm only): `groups[norm]` collects `GuidKeep::key(raw)` values and org ids.
  - If the org is a class row whose `first` is None, set
    `first = (notice, section, raw, scheme, roles, stratum, target index)` and `row.stratum = stratum`. Ascending
    order makes this its lowest (notice, section).
- At the end of each notice, every name group with 2 or more distinct values is a twin group:
  - `twin.groups += 1`, `twin.mentions += group mentions`, and its class rows get `twin = true`;
  - a notice with at least one group adds `twin.notices += 1`;
  - a sample is listed while under `samples`.
- Progress: `(done, "reading cf35 notices: {done} of {total}")`.

**Phase 3: the targets.**
1. Distinct name_norms → IN chunks of `guid_twin_targets_sql` (`stop()` before each). Match `(name_norm, country)`
   to the key; the lowest id wins, as at guid_twins.rs:1554-1564.
2. For each found target, read `stop()` every 64 targets (missing ones included):
   - `GUID_TWIN_TARGET_COUNT_SQL` → `target_mentions`;
   - `GUID_TWIN_TARGET_NEWEST_SQL` with `GUID_TWIN_TARGET_NEWEST` → newest `(notice, section)` pairs.
3. The newest pairs' notices → IN chunks of `guid_twin_cities_sql` (`stop()` before each) → the target's `cities`.
4. Per target:
   - `city_absent` = the sum of `planned_cities[c]` for each c not in `cities`, when `cities` is non-empty;
   - `multi_city` = `cities.len() >= 2`; `multi_city_planned` = `planned_cities.len() >= 2`.
5. Screen totals: `city_absent_targets` counts targets with `city_absent > 0`; `planned_multi_city_keys` counts keys,
   found or missing.

**Finish** (a sync free fn `hex_census_finish(report, walk, &args)`, off the async frame):
- stable = `row.mentions >= args.stable_mentions`.
- Tally every class row into: `class.all`, `by_country`, `by_first_year`, `by_source`, `by_profile` (then capped),
  and `by_stratum`.
- Counts: `other_shape_mentions` = mentions − cf35; `mixed_shape_rows` = rows whose shape bits hold cf35 and any
  other bit except `none`; `keep_530_overlap`; `v4_rows`; `notices` = the walk-wide set's len; `tenders` =
  `class_tenders` len.
- Value maps keyed by `GuidKeep::key(identifier)`: `values_multi_row` = values with 2 or more rows;
  `values_multi_tender` = values whose rows' tender union has 2 or more.
- Targets: keys, found, missing, `mentions_to_found` / `_missing`, then `top`, `city_flagged` and `ccira` (sort and
  caps as in §2.5).
- Samples:
  - `r2_random`: for each `(stratum, n)` of HEX_CENSUS_R2_STRATA, the class rows of that stratum sorted by
    `guid_twin_sample_key(id, HEX_CENSUS_SALT)`, the first n;
  - the whole lists (cap GUID_TWIN_LIST_CAP) and the `samples`-capped lists, as in §2.5;
  - `tenderer_key.rows` and `.procedures` are the set lens; collisions and their samples come from `stripped`.
- Canaries: each id in `args.canaries` that is a class row → `canaries`, in the given order. Any other id →
  `canaries_absent`.
- Fill `window`, `stable_mentions`, `samples_per_list`, `salt` and `not_measured`.

A `HexRowSample` is built from a class row plus its `first` and its target's resolved id (`target_id` is `None`
for a missing or unkeyed target; `target_name_norm` is `None` only when unkeyed).
